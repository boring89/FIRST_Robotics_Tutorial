# 第 4 章 機器人程式基礎

--8<-- "alpha-warning.md"

終於要寫機器人程式了！這章會從最簡單的架構開始，讓一顆馬達轉起來、用手把控制它，再把程式部署到 Systemcore 上執行。

## 這章學什麼

- 機器人程式和一般程式哪裡不一樣
- 機器人的各種模式，以及每個模式會呼叫哪些方法
- 建立馬達控制器物件，讓馬達轉起來
- 讀取手把的搖桿和按鈕
- 部署程式、看輸出訊息、用 Telemetry 顯示資料

**需要先讀**：[第 1 章 Java 速成](../01-java/index.md)、[第 3 章 環境建置](../03-setup/index.md)

## 機器人程式哪裡不一樣

第 1 章的程式從 `main` 開始，由上往下執行完就結束了。機器人程式不一樣：

| 一般程式 | 機器人程式 |
| --- | --- |
| 執行完就結束 | 一直執行，直到關機 |
| 自己決定什麼時候做什麼 | WPILib 每 20 ms 呼叫一次你的方法 |
| 寫錯頂多印出錯誤訊息 | 寫錯可能讓機構撞壞、讓人受傷 |
| 自己決定流程 | 由 Driver Station 和場地決定現在是哪個模式 |

所以寫機器人程式要換個想法：**不是「先做這個、再做那個」，而是「每 20 ms，根據現在的狀態，決定這一刻要做什麼」**。

## 這章的練習專案

這章要學的是最基本的架構，所以用另一個比較簡單的範本：

1. 用 **WPILib: Create a new project** 建立新專案，Project Base 選 **Timed Robot**，專案名稱例如 `Ch4Practice`
2. 依照隊上用的馬達，加入 REVLib 或 Phoenix 6（見 [建立第一個專案](../03-setup/first-project.md#4-加入廠商函式庫)）

這章所有的程式都寫在 `Robot.java` 裡。到了 [第 5 章](../05-commands/index.md)，會改用 Command-based 架構，把程式整理成好幾個類別。

## 需要的硬體

| 硬體 | 數量 |
| --- | --- |
| Systemcore | 1 |
| 馬達控制器 + 馬達（REV 或 CTRE 都可以） | 1 組，已設定好 CAN ID |
| 手把 | 1 |
| 裝好 FIRST Driver Station 的筆電 | 1 |
| 電池、電源接線 | 1 組 |

沒有硬體也可以先讀，[延伸學習](further.md) 會介紹怎麼用模擬執行程式。

!!! warning "注意：馬達要先固定好"
    這章會讓馬達真的轉起來。測試前，把馬達固定在桌上或機構上，**不要接任何會撞到東西的機構**，周圍的人也要知道你在測試。
