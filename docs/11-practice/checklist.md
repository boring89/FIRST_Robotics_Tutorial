# 賽場檢查清單

## 這頁學什麼

- 比賽前、每場比賽前、比賽後要檢查的項目
- 為什麼需要檢查清單

## 觀念

比賽現場很吵、很趕，很多問題不是程式寫錯，而是**忘了做某件事**：忘了選自動程式、手把順序插反、電池沒換。**檢查清單 (Checklist)** 讓這些事每一場都確實做到，不依賴任何人的記憶力。

建議把下面的清單印出來護貝，放在 pit 和駕駛站，每場比賽照著打勾。依照隊上的機器人增減項目。

## 出發比賽前

- [ ] 比賽用的程式已經合併到 `main`，並打上標籤（例如 `event-1`）
- [ ] 至少兩台程式組筆電能**離線**編譯和部署（見[第 3 章](../03-setup/further.md#比賽前的離線準備)）
- [ ] 所有筆電的 WPILib、vendordep、Driver Station 版本一致
- [ ] Systemcore 映像檔、馬達控制器韌體的版本記錄下來，比賽期間不更新
- [ ] 準備好 USB 隨身碟（存 log）、備用的網路線和 USB 線
- [ ] 每個自動程式都在練習場的紅、藍兩邊測試過

## 每場比賽前（在 pit）

- [ ] 換上充飽的電池
- [ ] 部署的程式已經 commit，記下這場用的版本
- [ ] Enable 機器人，每個機構動一次：底盤前後左右、Intake、Shooter、手臂
- [ ] 確認感測器讀值正常：IMU 的朝向、編碼器、極限開關、相機（看 Elastic）
- [ ] 沒有任何 Alert
- [ ] 機器人擺回起始位置的方向，**重設 IMU 的朝向**（如果你的程式需要）

## 上場前（在排隊區和駕駛站）

- [ ] Driver Station 的**隊號**正確，連上場地系統
- [ ] 手把插好，**手把順序**正確（主駕駛 0、副駕駛 1）
- [ ] Driver Station 顯示的**聯盟顏色和站位**正確
- [ ] Elastic 上的**自動程式選好了**，和聯盟隊友討論過的一致
- [ ] 機器人擺放的位置和方向，和自動程式預期的一致
- [ ] 電池電壓正常（Driver Station 上顯示 12.5 V 以上）

## 比賽中

- [ ] 注意 Driver Station 的訊息和電池電壓
- [ ] 記下發生問題的時間點（例如「手動階段開始 30 秒左右，Intake 卡住」）

## 下場後

- [ ] 下載 log（或拔下隨身碟），用場次重新命名
- [ ] 問駕駛：有沒有什麼不正常的地方？哪些操作不順手？
- [ ] 用 log 確認問題的原因（見[用 AdvantageScope 看 log](logging.md#用-log-找問題的例子)）
- [ ] 檢查機構有沒有鬆脫、撞壞，告訴機構組
- [ ] 需要修改程式的話，先在 pit 測試，再 commit
- [ ] 換下來的電池拿去充電

## 常見錯誤

!!! bug "常見錯誤：每個人都以為別人做了"
    「我以為你選好自動程式了」。每個項目都指定由**誰**負責檢查，例如程式組負責自動程式和程式版本，駕駛負責手把。

!!! bug "常見錯誤：清單太長，最後沒人照著做"
    清單要短到能在幾分鐘內做完。剛開始可以只列最重要的幾項，遇到新的問題再加進去。

## 小練習

1. 依照你們隊上的機器人，修改上面的清單：刪掉用不到的項目，加上你們機器人特有的檢查。
2. 在練習時模擬一次完整的比賽流程，照著清單做，計時看看要花多久。
3. 回想一次比賽中發生的問題，如果有檢查清單，能不能事先發現？
