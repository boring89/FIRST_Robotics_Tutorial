# 這份教學怎麼讀

## 這頁學什麼

- 依照自己的程度，選擇適合的閱讀路線
- 看懂每一頁的固定結構和提示框
- 知道怎麼使用程式碼區塊和 REV / CTRE 分頁

## 選擇閱讀路線

=== "完全沒寫過程式"

    依序讀下去就對了：

    1. [第 1 章 Java 速成](../01-java/index.md)：先學會寫 Java
    2. [第 2 章 FRC 基本元件認識](../02-hardware/index.md)：認識機器人的硬體
    3. [第 3 章 環境建置](../03-setup/index.md) 之後：開始寫機器人程式

    第 1 章每頁都有小練習，**一定要自己動手打**，不要只用看的。

=== "會寫一點程式"

    1. 快速看過 [第 1 章](../01-java/index.md) 每頁的「常見錯誤」，確認自己沒有觀念漏洞。[Lambda](../01-java/lambda.md) 那頁建議完整讀，FRC 用得非常多
    2. 讀 [第 2 章 FRC 基本元件認識](../02-hardware/index.md)
    3. 從 [第 3 章 環境建置](../03-setup/index.md) 開始動手

=== "用過 2026 以前的 WPILib"

    2027 改動很大，建議讀：

    1. [第 2 章 FRC 基本元件認識](../02-hardware/index.md)：Systemcore、Motioncore 的新觀念
    2. 每頁的 **2027 新改動** 提示框，會標出和舊版不一樣的地方

## 每一頁的結構

除了章節首頁和延伸學習，每一頁都照這個順序寫：

1. **這頁學什麼**：讀完能做到什麼
2. **觀念**：先講為什麼，再講怎麼做
3. **範例**：可以直接複製來試的程式碼（硬體章節是「動手看看」）
4. **常見錯誤**：新手最常踩的坑
5. **小練習**：自己試試看的題目

每一章最後有一頁 **延伸學習**，放進階主題和外部資源，第一次讀可以先跳過。

## 提示框

文章中會出現這幾種提示框：

!!! tip "小技巧"
    好用但不是必要的做法。

!!! warning "注意"
    會弄壞東西或造成危險的事，**一定要讀**。

!!! bug "常見錯誤"
    新手常犯的錯，先知道就能少花很多時間除錯。

!!! info "2027 新改動"
    和 2026 以前不一樣的地方。

??? question "想一想"
    思考題。點一下標題就能展開，看參考答案前先自己想想。

## 程式碼區塊

程式碼區塊右上角有複製按鈕，點一下就能複製整段程式碼。

```java
IO.println("Hello, FRC!");
```

## REV / CTRE 分頁

FRC 最常見的兩家廠商 REV 和 CTRE 的程式寫法不同，需要分開寫的地方會用分頁呈現：

=== "REV"

    這裡是 REV 的寫法。

=== "CTRE"

    這裡是 CTRE 的寫法。

切換一次之後，**整個網站的分頁都會同步切換**，隊上用哪一家就選哪一家。

## 專有名詞

FRC 的資料幾乎都是英文，所以這份教學的專有名詞以英文為主，第一次出現時會附上中文翻譯，例如 Encoder（編碼器）。之後就直接用英文。

忘記某個名詞的意思時，可以查 [名詞對照表](../appendix/glossary.md)，或用右上角的搜尋。
