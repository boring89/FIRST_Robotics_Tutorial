# 延伸學習

這一節的內容不是必讀，第一次讀可以先跳過。

## 官方資源

- [FIRST 官方網站](https://www.firstinspires.org/)：FRC 的介紹、賽季資訊、賽季手冊 (Game Manual) 下載
- [WPILib 官方文件](https://docs.wpilib.org/en/latest/)：FRC 程式的官方文件，遇到問題時第一個查的地方。這份教學會常常附上連結
- [The Blue Alliance](https://www.thebluealliance.com/)：所有 FRC 比賽的賽程、成績和比賽影片

## 社群

- [Chief Delphi](https://www.chiefdelphi.com/)：全世界 FRC 隊伍交流的論壇。遇到奇怪的問題時，搜尋一下常常能找到別隊遇過一樣的狀況
- **其他隊伍的程式碼**：很多強隊會在 GitHub 公開整個賽季的程式碼。等你讀完第 5 章，可以試著讀讀看別隊怎麼寫

!!! tip "小技巧：怎麼問問題"
    在論壇或向學長姐問問題時，附上這些資訊能讓別人更快幫你：

    1. 你想做什麼
    2. 你做了什麼（附上程式碼）
    3. 你預期發生什麼、實際發生什麼
    4. 完整的錯誤訊息（用複製的，不要截圖或只寫「它壞了」）
    5. 用的 WPILib 版本和廠商函式庫版本

## 看比賽影片

在 The Blue Alliance 或 YouTube 找前一年世界賽的比賽影片，特別注意：

- 自動階段的十幾秒，強隊的機器人做了哪些事？
- 駕駛在手動階段有哪些動作是「一個按鈕」自動完成的？

這些都是程式組的工作。看完影片，你會更清楚之後要學的東西會用在哪裡。
